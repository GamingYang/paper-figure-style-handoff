# 可执行美术规范

## 字体、大小与导出

- 所有英文与数字：Times New Roman。`font_manager.findfont(..., fallback_to_default=False)` 确认实际字体，不凭 rcParams 声称已生效。
- `mathtext.fontset='custom'`，罗马、斜体和粗体分别映射到 TNR，避免一半新罗马一半 STIX。特殊符号如缺字须查实处理。
- 图内英文字体一般 7–9 pt；紧凑数值约 6.5–7 pt。以最终排版尺寸评估，不能仅靠导出高 dpi。
- 保存 PDF 时 `pdf.fonttype=42`；SVG 用 `svg.fonttype='none'` 保留文字。SVG 是否保持字体还取决于打开者电脑。
- 默认白底，PNG 600 dpi；矢量 PDF/SVG 同时交付。TIFF 使用无损 LZW 压缩。

## 色板

跨子图同一方法保持同一颜色，具体字典在 `style.json`。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Proposed | `#12A7C9` | 青色主方法，轮廓略粗 |
| Static MMD | `#66BD9D` | 绿色系对照 |
| w/o adaptive MMD | `#B95CE5` | 紫色对照 |
| w/o degradation state | `#39B56B` | 绿色对照 |
| w/o curve tokens | `#F26A5B` | 珊瑚色对照 |
| fixed temperature | `#7C6FE3` | 紫蓝色对照 |
| Original attention | `#E9AA31` | 金黄色对照 |
| w/o physical base | `#E84C4F` | 红色对照 |
| 数值、轴线、刻度 | `black` | 不用方法颜色给小字染色 |
| 网格 | `#E5E5E5` | 轻量辅助，不盖住数据 |

颜色不是唯一编码：接近的线再配不同 marker 或线型；雷达线宽区分主方法。不要声称这组色板天然满足所有色觉条件，若投稿要求需另做色觉检查。

## 编号与文字

Cartesian 子图直接 `ax.set_xlabel('a) Token position')`。没有常规横轴的雷达用 `ax.text(0.5, negative_y, 'a) MMD control', transform=ax.transAxes)`。不要在上方再放一遍 a。分面标题仅保留确有必要的短词；说明性长句放图注。

留白应由布局承担：`GridSpec`、`subplots_adjust` 和单独 legend/colorbar 区域。不能以无限缩字号或把标签丢到图外替代布局。

## 柱图与误差线

数字含义仍为均值，但标注锚点是 `mean + upper_error`，再用 `xytext=(0, 6), textcoords='offset points'` 留空。上限至少覆盖最高误差线和文字。非对称误差用上侧误差，不能错误地用下侧。

这比 `bar_height + constant` 稳定：误差线长短变了，数字仍不会穿过竖线。柱图不作为特定消融图的首选，但样例和通用技巧保留。

## 雷达

五边形来自五个真实维度。历史示例是 Early、Middle、Late、Overall、Macro 五种 RMSE 汇总，统一单位 % SOH，越小越好；后两者是统计汇总而非第四、第五退化阶段。

- 分为 MMD、attention、physical prior 三个问题，每图 3–4 条线。更多线优先拆分。
- 轻填充 alpha 约 0.10，轮廓接近全不透明，避免多层变蓝灰。历史参考的轻纹理可选，不强制所有图斜线填充。
- 五边形网格、顶部起点、顺时针；本包便携模板从真实零点开始，共用径向上限。
- 数值黑色，使用 points 偏移并检查文字包围框；移动较远时短引线连到实际顶点。若近邻过密仍无法辨认，拆图，不能继续把数字远移。
- 横/竖版共用同一数据、色板、组别、轴顺序与标尺。不能用重排版为理由暗改数据。
- 不用多边形面积给方法排名，也不要把相关汇总指标称作五条独立证据。

新论文若只有 3 个指标：可考虑 5 个真实方法作为顶点、不同指标分面；或再提供两个有定义的指标。不能填充重复轴、插值轴或臆造数据只为了外形。

## 注意力曲线与响应面

曲线颜色编码应附着在曲线上：由相邻实际点组成 `LineCollection`，线段权重取相邻 token 权重的平均。主线 alpha 接近 1，约 2–3 pt；不要用散落矩形、圈圈或额外散点代替。

为了展示多个阶段，可以对每条曲线幅值归一化再加垂直偏移，但 y 轴必须标注 `Voltage (offset)`，图注解释其不是原始电压幅值比较。色彩是注意力强弱，不能改变曲线几何制造趋势。

温度/熵双轴：所有轴元素黑色；温度蓝实线圆点，熵红虚线方点；合并 legend。不要将“轴黑色”理解成“所有线黑色”。

响应面：`contourf` + 少量轻等高线；共享颜色范围时才共用色条。色条独立 `cax`，右侧预留空间。可以保留一个橙色参考中心点，配白色虚线；没有说明目的的黑点云不默认叠加。数据点若属于正式科学证据则另行解释或单独附图，不能为美观抹掉异常。

## 小提琴与机制消融

小提琴有足够真实观测且非零方差时才估计密度，叠加真实点、median/IQR；当只有少数训练 seed，不能靠平滑制造“稳定分布”。历史样例的 violin 单位为电芯×seed，黑菱形另表示每个 seed 的 pooled RMSE。

机制消融采用差值图，零线对应完整模型。区分：结果差值、每方法标准差、配对差值置信区间。三者不是一回事。图形用于承接“假设-证据-贡献”，不能把某项删掉后分数升降直接解释成因果机制已证实。

## 禁止自动继承的历史习惯

- 历史脚本的 Arial、总标题、顶置字母不覆盖用户后来的要求。
- 早期三角雷达、全部方法挤在同图、深蓝灰叠色不作为默认模板。
- 历史雷达的径向偏移和分面单独标尺不作为通用美术技巧。
- 不为“好看”补 seed、删异常、改变 RMSE、平滑掉预测误差或伪造参数搜索。
- 不自动沿用另一个 skill 关于训练曲线 EMA 的默认建议；需要平滑时另行说明并保留原始值。
