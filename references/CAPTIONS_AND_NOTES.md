# 独立图注与必要解释

以下对应包内真实样例，是后续写图注的起点，不是可直接套给新论文的结论。换数据后必须重写模型名、实验对象、样本单位与趋势描述。

## 1. 雷达图

**英文图名：** Stage-wise and aggregate RMSE profiles of mechanism controls.

**中文说明：** 按 MMD 控制、注意力内部机制和物理先验分组比较各模型的误差轮廓。五个顶点分别为 Early、Middle、Late、Overall 和 Macro RMSE，单位为 % SOH，数值越小表示误差越低。Overall 为合并样本 RMSE，Macro 为电芯 RMSE 的等权平均；二者不是新增退化阶段。各面板采用相同径向标尺，数字为真实 RMSE。

横竖版内容相同，只改布局。不要以多边形面积论证总体优劣；五项统计有相关性。

## 2. 注意力机制图

**英文图名：** Degradation-state-guided curve attention: focus profiles and conditional responses.

**中文说明：** a，三个阶段的代表性电压 token 曲线，各曲线经幅值缩放和垂直偏移以便比较形态，线段颜色从灰蓝至橙色表示注意力增强。b，各阶段平均注意力权重。c，归一化循环分箱内的平均温度与熵，蓝色圆点实线与红色方点虚线分别对应左右轴。d–f，固定晚期状态和汇聚上下文后，电压水平、一次差分与二次差分的二维条件兼容性响应；橙色点为相应特征的注意力加权中心。

这些响应面分别 min-max 归一化，展示形态而不是跨面绝对响应幅值。历史实现使用 pooled context 作为条件近似，不等于逐 token 实际隐藏状态上的 softmax 权重，不应称为参数优化图或因果解释。三阶段阈值基于 cycle/3000，不是逐电芯终寿命归一化。

## 3. 消融差值图

**英文图名：** Changes in prediction error under mechanism-specific controls.

**中文说明：** 两个面板分别表示各控制相对于 Proposed 的平均 RMSE 和 MAE 差值。负值表示误差较低，零竖线表示相同均值。横向误差线为各方法自身跨 seed 的标准差，用于描述方法误差波动，不是差值的标准差或置信区间。

某控制点低于零应照实报告；不能写“完整模型在所有控制中最优”。若研究重点是显著差异，应另外计算 seed 配对差值并报告适当不确定性。

## 4. 小提琴图

**英文图名：** Cell-wise prediction variability across repeated training seeds.

**中文说明：** 小提琴和细点展示每方法 3 个训练 seed、8 个电芯所形成的 24 个 cell-seed RMSE，横线和粗竖段分别表示中位数和四分位区间；黑色菱形是各 seed 的 pooled RMSE。该图包含电芯异质性和 seed 波动，不能单独称为 24 次独立训练的稳定性分布。

## 5. 其他样例

- **柱图避让：** 数字表示均值，竖线为 seed 标准差；文字摆在均值+标准差上方只是为了排版，数字本身不是上界。
- **电芯误差：** seed42 下每电芯 RMSE/MAE，单位 % SOH。
- **SOH 曲线：** seed42 下电芯69–76的真实与预测 SOH；保留原始曲线，不为好看平滑掉偏差。
- **极坐标柱图：** 每电芯对多个方法的 RMSE，统一半径，数字键由共享图例映射到方法；不是连线型雷达。

## 机制消融叙事框架

沿用用户“假设-证据-贡献”路径，但结论必须由实际对照支持：先问现有聚合是否默认不同退化阶段具有相同关注依据；再用状态移除、打乱或替代测试状态与输入的匹配作用；用曲线 token 对照测试局部形态信息；用固定温度对照测试聚焦强度的自适应性。还需考虑参数量、训练协议、噪声和阶段异质性等替代解释。

这套实验提供区分机制解释的证据，不自动等同于数学上或因果上的独立贡献证明。voltage-only 等结果优于完整模型时，要保留这个边界，而不是为了故事完整删去控制。
