# 输出前检查

这份清单用于实际查看导出图，不是只看脚本就打勾。自动结果见 `qa/validation.json`；最终人工检查记录见 `qa/REVIEW.md`。

## 数据与定义

- 核对方法、阶段、样本数、seed 数、单位和原表；`*_pct` 不重复乘100。
- 核对重复样本与独立训练次数，不把 cell-seed、cycle、bootstrap 当新增训练。
- 雷达的五个维度确实存在，不能补假轴；明确越大/越小越好，跨图标尺是否一致。
- 数据不变时横竖图指标顺序、颜色和数值一致。
- 差值误差线的类型写清楚，不误称配对 CI。
- 机制曲面的输入、条件化变量、归一化和颜色含义写清楚，不能当 RMSE 优化或因果证明。

## 字体与文字

- 实际 font path 指向 Times New Roman；英文、数字和公式字形一致。
- 无总标题/解释性页脚；正文解释在单独图注。
- `a) …` 在底部，与横轴说明一起；没有重复上方字母。
- 所有数值黑色，雷达数值靠近对应顶点，不存在读不出归属的孤立数字。
- 以最终印刷大小检查字体；高分辨率不能补救物理字号过小。

## 遮挡与裁切

- 柱顶数字高于误差线上端和帽线，并留 4–8 pt 间距。
- 雷达近邻数字不重叠、不盖图例；移动较多的数字有短引线或拆图。
- 机制图 f 右侧色条与 f 的绘图区、刻度、轴名分开。
- 双轴所有轴元素黑色，彩色曲线的图例可读，不盖住关键转折。
- 曲线上的注意力色段沿真实曲线，不悬空；无未经说明的点云。
- 底部子图说明和下一行子图、全图 legend 不相撞。
- PNG/PDF/SVG 未裁去字母、数值、单位或图例。`bbox_inches='tight'` 不是无遮挡的保证。

## 自动筛查的边界

布局 JSON 只筛查可见文字的包围框，不判断科学解释、所有数据线遮挡、短引线归属、色觉可读性或最后缩放后的字号。Matplotlib 会创建轴范围以外的 tick Text，脚本排除这些未实际绘制的 tick 和隐藏的 twin 轴标签，避免假阳性。

如果筛查报告碰撞，先看导出图验证，再修复。不要为了得到零计数删除真实数值、跳过检查或缩小所有字体。必要时扩大版式、缩短标签、预留 legend 或拆分图。

## 交付

- 至少 PNG + PDF；有可编辑需求时 SVG；投稿要求时 TIFF。
- 交付生成代码、使用的数据、风格配置和独立图注。
- 写明已运行哪些入口以及没有覆盖的环境。
- 修改数据/代码后更新 MANIFEST；旧示例保留在 originals，不能覆盖原工程文件。
