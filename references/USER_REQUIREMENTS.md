# 用户要求与优先级

来源是本窗口用户可见对话。下面引文是相关原话的摘录，不补造时间或“最终验收”。后续针对同一问题的澄清优先于早期尝试；历史文件的存在不等于每个像素均获认可。

## 本次新增的交接要求

- 将经验写成可复用文字/skill；用一个新建文件夹保存。
- 包含 README、之前的语言要求、相关 Python 程序和美术风格。
- 新窗口能迅速理解，可用于新论文；尽量消除原工程绝对路径依赖。

## 本包额外采用的实现建议

以下是工程实现选择，不冒充用户原话：默认 600 dpi PNG + PDF + SVG；图面白底；主线约 1.3–1.8 pt；字体不可用时报错；文字边界框筛查；哈希记录；真实数据缓存；共用色板 JSON；雷达真实零点和同组统一标尺。它们可以根据新期刊、新数据和用户明确要求调整。

期刊所谓“Nature 风格”在这里指简洁、可读、清晰的学术表达，并非声称某个色值、字体或编号位置是 Nature 全刊的统一规定。用户的新罗马与底部编号偏好优先于外部模板的默认无衬线和左上角编号。
